# world/

Nothing in here is used by the game any more. Hobson generates its world from the premise the
player types: Nova invents the setting, the opening facts and every scene; Nova proposes the
candidate outcomes for each action; Strands Decider 2B decides between them and checks every
claim and every paragraph against the ledger.

`legacy/town.yaml` is the hand-authored six-scene town from the first build (22 Oct 2026), kept
for the record with `scripts/legacy/probe_wording.py`, which probed Decider's wording sensitivity
on it. The findings from that probe (concrete beats abstract, `impossible` as an action not an
outcome, danger authored not asked) still shape the generated version.
